help অন্য জিমেইলে কীভাবে ব্যবহার করবেন?
  1. উপরে "Download Source Code (.ZIP)" বাটনে ক্লিক করে ফাইলটি ডাউনলোড করুন।

  4. অথবা আপনি আপনার কম্পিউটারে আনজিপ করে npm install এবং npm run dev চালিয়ে লোকালিও ব্যবহার করতে পারবেন।
